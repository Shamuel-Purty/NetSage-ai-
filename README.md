# NetSage AI

### AI-Powered Network Fault Diagnosis and Evaluation

NetSage AI is an intelligent network troubleshooting
system designed to diagnose network faults using
Artificial Intelligence.

##  Live Demo

[Open NetSage AI Dashboard](https://netsage-ai-kr6p.onrender.com)

##  Features

- AI-powered network fault diagnosis
- Automated network evaluation
- Network troubleshooting recommendations
- Performance evaluation dashboard
- Responsible AI diagnostics

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini AI
